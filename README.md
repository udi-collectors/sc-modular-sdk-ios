# modular-ios

Public Swift Package Manager (SPM) mirror for the **Experian Modular iOS SDK** (Modular collector for iOS).

This repository holds the consumer-facing `Package.swift` and GitHub Release assets (versioned XCFramework zips) required to integrate Modular iOS via SPM:

```swift
.package(url: "https://github.com/experian-collectors/modular-ios", from: "x.y.z")
```

For SDK source, build, and release details, see the internal **Modular iOS** collector project.
